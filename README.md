## 🧠 The story

Too many tasks. Too little brain storage.

My Tasks is a simple task manager that helps turn overwhelming to-do lists into smaller, manageable steps.

Add a task. Split it into subtasks. Tick things off. Watch your progress grow.

Basically, a tiny personal assistant that doesn't judge your unfinished tasks.

## ✨ What can it do?

| Feature | The fun part |
|---|---|
| 📝 Main Tasks | Get those thoughts out of your head |
| 🧩 Nested Tasks | Break big missions into tiny steps |
| ☑️ Smart Checkboxes | Complete every subtask to complete the parent |
| 📊 Progress Bar | Watch your progress move |
| ✏️ Edit | Changed your mind? No problem. |
| 🗑️ Delete | Let that task go |
| ⚡ Quick Add | Press Enter and it's on the list |
| 💾 Local Storage | Your tasks survive a page refresh |
